☁️ Live Sync Setup

Connects both phones to Firebase so any change either of you makes appears on the other phone instantly — no copy/pasting needed.

Step 1 — Go to console.firebase.google.com
Sign in with Google → Add project → name it anything → skip Analytics → Create
Step 2 — In your project click Build → Realtime Database → Create database → Start in test mode → Enable
Step 3 — Copy the database URL shown (looks like https://xxx-default-rtdb.firebaseio.com) and paste below
Step 4 — Create a secret room code (keeps your data private — only you and Lauren need it)
